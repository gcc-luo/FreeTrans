# ferdium-internal-server
用于存储设置/首选项的 Ferdium 内部服务器，无需登录外部服务器。

## 与 ferdium-server 的区别
- 不包含用户管理（只有一个用户）
- 不需要登录
- 无配方创建功能
- 包含 `start.js` 脚本以允许通过脚本启动服务器
- 使用 `env.ini` 而不是 `.env` 以保持与 Ferdium 构建脚本的兼容性
- 仅允许 Ferdium 客户端连接到 API

## 配置
`ferdium-internal-server` 的配置保存在 `env.ini` 文件中。除了 AdonisJS 的设置外，`ferdium-internal-server` 还有以下自定义设置：
- `CONNECT_WITH_FRANZ`（`true` 或 `false`，默认值：`true`）：是否启用与 Franz 服务器的连接。通过启用此选项，`ferdium-internal-server` 可以：
  - 显示完整的 Franz/Ferdi 配方库，而不仅仅是自定义配方
  - 导入 Franz/Ferdi 账户

## 导出备份
由于 `ferdium-internal-server` 运行本地服务器，无法自动同步设置。您可以通过点击 `帮助 > 导入/导出配置数据` 来备份您的设置，这将在浏览器中打开正在运行的服务器页面。选择导出选项并保存生成的文件。

## 导入您的 Franz/Ferdi 账户
`ferdium-internal-server` 允许您导入完整的 Franz 账户，包括其所有设置。

要导入您的 Franz/Ferdi 账户，在 Ferdium 中点击 `帮助 > 导入/导出配置数据`，这将在浏览器中打开正在运行的服务器页面。然后您可以使用您的 Franz 账户详细信息登录。`ferdium-internal-server` 将创建一个具有相同凭据的新用户，并复制您的 Franz 设置、服务和工作区。
