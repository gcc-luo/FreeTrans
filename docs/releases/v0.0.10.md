# FreeTrans v0.0.10

本次更新完善 WhatsApp 文字消息翻译，增加已加载历史消息补译，让首次打开与持续聊天都更方便。

## 新功能

- **历史消息补译**：在 WhatsApp 聊天中点击“翻译已加载历史消息”，查看处理进度、翻译、跳过及失败数量。再次执行会跳过已完成的消息，并允许重试失败项。
- **会话语言设置**：为当前 WhatsApp 聊天单独保存发送目标语言，或继续沿用服务默认语言。
- **输入框附近的译文预览**：发送前查看并编辑译文，确认后再发送；也可以取消并保留草稿。

## 可靠性改进

- 快速连续发送仍逐条进入翻译流程，避免发送放行窗口导致原文漏翻。
- 观察新消息气泡后再记录本地发送原文；发送状态不明时提供恢复提示，避免自动重复发送。
- 会话、语言设置或消息内容变化后，丢弃过期译文。
- 接收翻译与历史补译采用有限并发，新消息优先处理。
- 译文与原文相同时不再直接误报失败；细化网络、凭据、限流和语言组合错误提示。
- 历史任务可停止，切换会话或修改相关设置会取消旧任务。

## 使用范围与验证

- 历史补译针对当前 WhatsApp 页面中已加载、可识别的对方消息。更早记录需先向上滚动加载，不会一次抓取账号的全部历史会话。
- 翻译文本会发送给所选翻译服务；触发回退时可能使用备用服务。本机缓存可以关闭或清除。
- 自动化覆盖 33 项模拟端到端测试和 8 项相关单元测试；模拟验证不能替代真实服务登录后的兼容性验证。
- 项目仍存在 27 个既有类型检查错误，完整类型检查尚未通过。

## 安装包

- Windows x64：下载 `.exe` 安装程序。
- macOS Apple Silicon：下载 ARM64 `.dmg`。
- macOS Intel：下载 x64 `.dmg`。

macOS 安装包的实际签名状态以构建配置为准；临时签名不等于 Developer ID 签名或 Apple 公证。应用内检查更新后，通过浏览器下载安装包并手动完成安装。
