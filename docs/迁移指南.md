# 迁移账户数据

本指南旨在向您展示如何从在线服务器或从无账户会话中导出您当前的 Ferdi 设置，以便安全保存、备份或仅使用浏览器传输到新实例。

在详细介绍使用在线账户与无账户的区别之前，让我们快速回顾一下两者之间的差异：

## 使用带账户的 Ferdi

使用带账户的 Ferdi 的主要优势是您的配置数据存储在云端——因此，当您移动到不同的机器时，一旦登录，所有这些配置都会应用到您新机器上的 Ferdi 实例。

**但是**，如果您使用 Ferdi 账户，您需要访问他们的服务器。如果服务器无法访问，您就没有其他获取数据的选择，因为没有本地副本。因此，建议在有机会时尽快执行此操作——只是为了安全起见。

## 使用不带账户的 Ferdi，即无账户模式

无账户实例具有与基于账户的实例相同的功能，但多机同步除外。如果您不打算在多台机器上使用此应用，并且设置和服务列表经常变化，那么拥有在线账户就没有好处。每当您对设置进行更改时，备份您的 `export.ferdi-data`，提供了一种类似安全（尽管更慢且手动）的自动同步替代方案，不依赖于服务器的持续可用性。

## 导出

根据您账户所在的位置，您必须访问不同的站点来检索它。这不会影响您当前的实例。无论哪个在线服务器保存您的数据，您都可以按照以下步骤访问和导出该数据。

1. 在您的系统上运行 Ferdi。（即使您在初始"开始使用"页面上，这些说明也会起作用。）
2. 转到 `帮助 > 导入/导出配置数据`，这应该在您的默认浏览器中打开相应的 URL。
3. 点击 `将您的数据导出为 ".ferdi-data" 文件`。
4. 将 `export.ferdi-data` 文件保存到您想要的任何位置以便安全保存/备份。

## 导入

1. 在您的系统上运行 Ferdium。
2. 当您到达显示"开始使用"的屏幕时，转到 `帮助 > 导入/导出配置数据`，这应该在您的默认浏览器中打开本地 URL。
3. 点击 `从 ".ferdium-data" 或 ".ferdi-data" 文件导入您的数据`。
4. 使用文件浏览器按钮，在您的系统上找到之前保存的 `export.ferdi-data` 文件，然后点击"导入数据"按钮。
5. 重启您的应用程序。

_注意：_

1. 设置新实例或迁移到无账户设置将需要手动重新登录所有服务。这是因为会话信息只保留在您的本地机器上——永远如此。
2. 导入数据不会覆盖您现有的本地服务列表（如果您有任何），而是将它们添加到当前列表。这是正常行为。如果您不想处理重复的服务实例，可以在从之前导出的数据文件导入之前删除您预先存在的服务。
3. 由于当前失去对 Ferdi 服务访问权限的风险，建议将来不要使用他们的服务器。如果您等待官方 Ferdium 解决方案（如果自动同步对您很重要），您应该设置自己的服务器。
